# 职业探索自我画像问卷（短版试点稿）

**版本：** 0.1｜**状态：** 团队评审稿，尚未接入线上问卷或正式计分  
**适用对象：** 第一阶段面向上海对外经贸大学本科生；后续可迁移到其他高校  
**预计用时：** 约 4 分钟｜**题量：** 16 个作答项，另有 1 个可选经历补充  
**性质：** 产品自编的生涯探索工具，不是临床心理测验、标准化能力测验或经过信效度验证的职业测评。

## 1. 问卷说明

请按“目前的真实情况”作答，不需要猜测系统期待的答案。测评用于整理兴趣、工作价值、能力自评、工作方式和探索准备度，帮助你比较职业方向。结果是讨论起点，不替你决定专业、职业或未来规划。

- 1–5 分题：1 表示“完全不符合 / 很不愿意 / 目前几乎不会”，5 表示“非常符合 / 很愿意 / 能独立做好并处理复杂情况”；中间分值表示程度递增。
- 可跳过不确定的题目。漏答保留为“未知”，不按 0 分、不补成中间值。
- 能力题是自我评价，不代表客观技能水平；如果缺少经历证据，结果会明确标注“仅有自评”。
- 不收集诊断、家庭、健康或其他与职业探索无关的敏感信息。

## 2. 题目

### A. 活动兴趣（6 题）

每题请选择 1–5 分：**如果本学期有机会，你愿意参与这类活动吗？**

| 编号 | 题目 | 兴趣维度 |
|---|---|---|
| I-R | 动手搭建、操作或改进一个具体产品、设备或流程，并观察它是否好用。 | R 实践 |
| I-I | 围绕一个商业或社会问题搜集资料、比较证据，弄清它为什么发生。 | I 研究 |
| I-A | 为活动、产品或内容提出新点子，并设计一种有吸引力的表达方式。 | A 创意 |
| I-S | 向同学解释复杂信息、帮助他人解决问题，或组织一次协作活动。 | S 社会 |
| I-E | 说服他人支持一个方案、协调资源，或推动团队把想法落地。 | E 企业 |
| I-C | 整理数据、核对细节、维护清楚可靠的记录，让工作按规则准确完成。 | C 常规 |

题干中的“本学期”用于让新生联系近期可想象的活动，不表示必须实际参加过。

### B. 工作价值（1 题）

**以下工作条件中，请选出你目前最看重的 3 项，并按重要程度排序。**

- 持续学习，有清楚的成长机会
- 有自主空间，能自己安排或决定部分工作
- 工作稳定，规则和预期比较明确
- 收入与回报有吸引力
- 与他人合作，能对团队或客户产生实际帮助
- 有机会承担责任、影响决策或获得认可

该题记录优先次序，不换算为 1–5 分；并列时允许同级排序。

### C. 能力自评（6 题）

请分别按目前水平打 1–5 分，不以“喜欢”代替“会做”。

| 编号 | 题目 | 能力维度 |
|---|---|---|
| A-1 | 我能搜集与问题相关的信息，判断来源是否可靠，并提炼重点。 | 信息搜集与研究 |
| A-2 | 我能读懂基础数据或图表，发现变化并说明可能的原因。 | 数据理解与分析 |
| A-3 | 我能把观点写成结构清楚、适合目标读者的文字。 | 写作表达 |
| A-4 | 我能清楚表达观点、倾听对方需求，并进行沟通协调。 | 沟通协作 |
| A-5 | 我能拆解任务、安排顺序、跟进进度并按时交付。 | 组织执行 |
| A-6 | 我能使用表格、数字工具或 AI 工具完成学习和工作任务，并检查输出是否可靠。 | 数字工具应用 |

### D. 工作方式（2 题）

每题选最接近目前自己的 1 项；没有“更好”的选项。

**D-1｜接到一项目标明确、但没有现成做法的任务时，我通常更愿意：**

1. 先找资料和例子，再拟出步骤。
2. 先动手试一个小方案，边做边调整。
3. 先和同伴讨论，汇总出共同方案。
4. 希望先拿到清楚的要求和流程。

**D-2｜做小组任务时，我目前更愿意承担：**

1. 搜集资料、核对事实或整理数据。
2. 写作、汇报或对外沟通。
3. 分工、排期和进度协调。
4. 提出新思路、设计表达或方案。
5. 按明确流程完成分配给我的部分。

### E. 探索准备度（1 题）

**目前你对自己未来可能发展的职业方向有多清晰？**

1. 还没有线索，希望从基础介绍开始。
2. 有一些兴趣，但还不了解具体工作。
3. 有几个候选方向，想比较它们的差异。
4. 有较明确的倾向，想核对能力要求和准备路径。
5. 已有暂定方向，想把课程、竞赛和阶段规划落下来。

### F. 可选经历补充（不计分）

**如果愿意，请写一件能说明你某项能力的具体经历**（课程作业、社团、兼职、志愿服务、竞赛或个人实践均可），并选择它支持的能力标签。没有经历或暂时不想填写，可以跳过。

- 经历描述：最多 300 字。
- 能力标签：信息搜集与研究、数据理解与分析、写作表达、沟通协作、组织执行、数字工具应用，可多选。
- 保存时将“能力自评”和“经历支持”分开；AI 不得把自述经历验证成客观能力分数。
- 首版可只在本地临时处理；若将来上传到云端，应另行取得明确授权并提供删除方式。

## 3. 计分和分析规则

### 3.1 兴趣得分

- R、I、A、S、E、C 各由对应的 1 道题得到 1–5 分；同时保留原始分和作答状态。
- 结果展示六类兴趣的分数；将最高的 2–3 类描述为“当前较愿意投入的活动”，不称作人格类型或职业适配度。
- 若最高分并列，全部显示为并列信号；若只答了部分题，只对已答维度计分，未答维度标为“未知”。
- 六个单题只是极短筛查，无法支持稳定的 RIASEC 类型判断。报告须显示“探索线索，建议结合后续经历复核”，不得称为正式 RIASEC 测评。

### 3.2 工作价值

- 显示用户选出的前三项及其顺序，不计算综合分、不与其他学生排名。
- 用于解释职业环境偏好，不直接决定职业推荐。

### 3.3 能力自评与经历证据

- 六项能力分别显示 1–5 自评，不合并为总能力分，也不生成“胜任概率”。
- 每项能力独立标注证据状态：有经历支持、仅有自评、待验证、未提供信息。
- 经历支持只说明“用户提供了相关经历”，不代表经历质量已经被第三方验证。
- AI 可以用经历内容解释能力信号，但不得复述整段答案；用户明确要求可查看时除外。

### 3.4 工作方式与准备度

- 工作方式以偏好原文或中性摘要显示，不按高低计分，不做性格定型。
- 探索准备度只决定下一步解释的颗粒度：低分优先提供方向入门和比较，高分优先进入课程、竞赛和学期规划；它不进入职业匹配排序。

### 3.5 推荐方向的分析顺序

1. 程序先计算题目分数、兴趣排序、能力自评和缺失项；工作价值及工作方式保持分类结果。
2. 将画像信号与经过资料核验的职业方向任务、技能要求和工作环境逐项对应。
3. 推荐理由至少说清“哪些任务相符”以及“哪些能力已有经历支持 / 仅有自评 / 仍待验证”。
4. 方向相关事实没有可靠来源时，写明“资料不足”，不由模型编造岗位要求。
5. 不展示伪精确适配率，不重复罗列用户逐题选项；结果页优先显示各维度得分、偏向、推荐方向及推荐原因。
6. 用户的专业、年级、发展目标和时间容量作为规划背景单独呈现，不混写成测评得分。

**报告示例句式：**

> 目前的兴趣更偏向研究与沟通类活动。你对信息搜集、写作和沟通的自评较高，其中沟通能力有课程小组或社团经历支持。某方向中的客户沟通和市场信息整理与这些线索相符；数据工具能力目前主要来自自评，建议结合课程或实践继续验证。该建议表示“值得比较”，不表示已经胜任。

## 4. 与现有产品题库的关系

当前生产分支的 assessment.json 仍是 10 题、interest / ability / decision 三维轻测；页面也按这三维渲染。本文是下一版题库和解释逻辑的评审稿，**不应通过只替换 JSON 就宣称产品已完成升级**。若团队采纳，实施时需同步更新：

1. 种子题库 schema、版本号与方法说明；
2. src/lib/content/index.ts 中的维度顺序；
3. 问卷 UI（价值选择、经历补充、分题型呈现）；
4. src/lib/assessment/scoring.ts 与相关单测；
5. 方向推荐输入、解释提示和画像数据迁移策略；
6. 公开 API 当前题目版本及用户旧答案的兼容处理；
7. 问卷隐私说明、移动端体验及无障碍验证。

本稿不改变旧题库、旧用户答案、云端 profile、AI 生成能力或生产站点。

## 5. 参考项目与使用边界

以下项目用于研究题目呈现、来源标注或实现方式；本文题干为知途自编，不直接复制其题面。开源代码许可证不自动代表其中每份题库、数据或量表都可脱离来源限制使用。

- [O*NET Interest Profiler（官方介绍）](https://www.mynextmove.org/explore/ip)：用于了解兴趣类别和职业探索的组织方式；本文没有宣称使用其正式题目或评分。
- [riasec-co 的 IPIP Basic Interest Markers 题库](https://github.com/affromero/riasec-co/blob/main/data/canonical/items_en.json)：仓库说明题库来源为 IPIP Basic Interest Markers，并注明 Liao、Armstrong 与 Rounds（2008）论文及 public-domain 属性；短版摘题仍不能继承原量表的信效度。
- [Careero 的 30 组视觉偏好题](https://github.com/nbjupiterr/Careero/blob/main/Careero/src/features/assessment/data/questions.json)：可参考轻量交互；其题库属于项目实现，不等同于经验证的标准化测验。
- [Career Compass 的测评题库](https://github.com/deniskostadinov1995/career-compass/blob/main/public/instruments.js)：可参考把兴趣、工作价值和情境题分开；项目注明其 Big Five 情境题未独立进行常模验证。

如果后续决定原样使用任何外部题目，应先逐题确认来源、具体授权、翻译/改写权利与署名要求，并保留原量表的适用边界。不能把“参考权威框架”写成“知途已使用经验证的权威心理测验”。
